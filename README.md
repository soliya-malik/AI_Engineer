# AI Engineer Journey

Welcome to the AI Engineer repository! This repository will document the journey and projects related to learning and building AI applications.

## Directory Structure

```text
AI_Engineer/
	week1/
		day1/
			hello_llm.py
		day1_llm_call/
		day2/
	week2/
		day1/
```

Keep each lesson inside its week folder. Add future lessons as `week1/day3`,
`week1/day4`, and so on; start a new week with `week2/day1`.
